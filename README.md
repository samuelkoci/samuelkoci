## Projects

### 🔵 [RISC-V RV32I Processor on FPGA](https://github.com/samuelkoci/Riscv-Single-Cycle-Fpga-NexysA7)
32-bit single-cycle CPU designed from scratch in SystemVerilog, deployed on Nexys A7-100T. Validated end-to-end with EEMBC CoreMark — **0.44 CoreMark/MHz**, bit-exact CRC against published reference tables. Key challenge: 5-state FSM to synchronize a nominally single-cycle design with synchronous Block RAM.

`SystemVerilog` `FPGA` `RISC-V` `Xilinx Vivado` `Bare-Metal C`
